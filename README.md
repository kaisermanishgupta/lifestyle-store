# Lifestyle Store 🛍️

A simple **e-commerce website project** developed during my **1st year of B.Tech.** as one of my early experiments with web development.

The project was built as a learning exercise to understand how an online shopping website is structured, including product browsing, user interaction, navigation, and basic e-commerce workflows.

## 🛒 About

**Lifestyle Store** is a web-based shopping website inspired by the structure and experience of an online lifestyle store.

The project was developed during my first year of B.Tech. when I was exploring **HTML, CSS, web design, and frontend development**.

It represents one of my early steps into software development and building complete applications rather than just individual programming exercises.

## ✨ Features

* 🏠 E-commerce-style homepage
* 🛍️ Product browsing
* 👤 User-oriented pages
* 🛒 Shopping/cart interface
* 🔐 Login / registration interface
* 📱 Responsive web layouts
* 🎨 Styled product and navigation pages

## 🛠️ Technology Stack

* **HTML**
* **CSS**
* **Bootstrap**
* **PHP**
* **MySQLi**
